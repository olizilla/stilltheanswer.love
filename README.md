# stilltheanswer.love

The website for Love Is Still The Answer (LISTA)

LISTA creates free community events that bring people together through live music, great food, and fundraising for local charities. Using the renowned hand-built Suena Bien Sound System and strong connections within the local music scene, we showcase talented emerging and established artists while supporting causes that make a positive difference in our communities.

We work closely with charities, community groups, and local businesses to organise inclusive events where entry is always free. Funds are raised through food and drink sales, helping charities increase both awareness and income while celebrating the work they do.

Our first event in January 2026 raised £700 for a youth music charity and demonstrated the power of community-led events to unite people around a shared cause. Since then, we have continued to develop partnerships, explore sponsorship opportunities, and expand our impact across South London.

LISTA is a Private Company Limited by Guarantee without Share Capital, established to deliver community-focused music and cultural events that benefit local charities and the wider community.

At LISTA, we believe success is measured not just by the money raised, but by the connections made, the communities strengthened, and the causes celebrated.


## Commands

Built with [astro](https://astro.build)

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
